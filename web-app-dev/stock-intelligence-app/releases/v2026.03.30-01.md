## Changes

- Secure checkpoint cron endpoints and repo-root GitHub Actions workflow for unattended intraday capture and EOD reconcile.

- Scheduled AI decision snapshots (intraday + EOD) with cache retention and backfill.
- Supabase email/password login, protected app shell, and bearer auth on all `/api/v1/*` routes.
- Watchlist market focus selector and improved focus refresh flow.

### Changed
- AI panel shows clearer payload-state cues for live checkpoint, cached EOD, partial AI, and fallback output.
- EOD mode uses overnight-cues wording, softer fallback copy, and next-market-open refresh messaging.
- Workflow docs record Render/GitHub checkpoint-automation setup and validation flow.

### Fixed
- Checkpoint board follows the selected dashboard index instead of staying hardcoded to Nifty 50.
- Shared NSE trading-day logic keeps EOD date selection and checkpoint TTL holiday-aware without `exchange_calendars`.
- Checkpoint capture and scheduler paths skip non-trading days.
- EOD AI fallback stabilized when cache is missing; EOD snapshots retained and backfilled.
