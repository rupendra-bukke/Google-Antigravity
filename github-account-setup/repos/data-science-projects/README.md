## Overview

Structured certification prep materials covering Azure data fundamentals, Fabric analytics engineering, and data engineering workflows. Each certification has a **Jupyter notebook** and a **Markdown companion** for dual-format study.

---

## Certification Guides

| Exam | Name | Notebook | Markdown | Level |
|------|------|----------|----------|-------|
| **DP-900** | Azure Data Fundamentals | `DP900_Azure_Data_Fundamentals_Guide.ipynb` | `.md` | Foundational |
| **DP-600** | Fabric Analytics Engineer | `DP600_Microsoft_Fabric_Analytics_Engineer_Guide.ipynb` | `.md` | Associate |
| **DP-700** | Azure Data Engineer | `DP700_Azure_Data_Engineer_Guide.ipynb` | `.md` | Associate |

---

## Study Approach

Each guide covers:

- Core concepts and exam objectives
- Service comparisons (Synapse, Fabric, ADLS, etc.)
- Architecture patterns and best practices
- Practice questions and key takeaways

---

## Getting Started

```bash
git clone https://github.com/rupendra-bukke/data-science-projects.git
cd data-science-projects
pip install jupyter
jupyter notebook DP900_Azure_Data_Fundamentals_Guide.ipynb
```

**Recommended order:** DP-900 → DP-600 → DP-700
