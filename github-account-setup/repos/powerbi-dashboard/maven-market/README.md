## Overview

| Field | Details |
|-------|---------|
| **Business purpose** | Analyze Maven Market retail performance across products, regions, and time |
| **Audience** | Business analysts, course portfolio reviewers |
| **Report file** | `MavenMarket_Report.pbix` |
| **Source data** | `data/Maven+Market+CSV+Files.zip` |
| **Attribution** | Based on [Maven Market Power BI course](https://github.com/SaheliM282/Maven-Market-Power-BI) materials |

---

## Skills Demonstrated

- **Power Query** — connecting to data, QA, text/number/date transforms, pivot, merge & append
- **Data modeling** — relationships, formats, categories, hierarchies
- **DAX** — calculated columns, measures, `CALCULATE`, `RELATED`, conditional logic, time functions
- **Visualization** — KPI cards, charts, maps, slicers, bookmarks, drill-through, tooltips

## How to Run

1. Extract `data/Maven+Market+CSV+Files.zip` if connecting to local CSV sources.
2. Open `MavenMarket_Report.pbix` in Power BI Desktop.
3. Update file paths or credentials as needed.
4. Refresh the model.
