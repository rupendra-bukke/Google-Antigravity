## Skills Demonstrated

1. **Data cleaning (Power Query)** — database connections, profiling, text/number/date tools, index & conditional columns, pivot, merge & append
2. **Data modeling** — model creation, relationship management, formats, hierarchies
3. **DAX** — measures, math/stat functions, `SWITCH`, text & date functions, `CALCULATE`, `ALL`, `RELATED`
4. **Visualization** — KPI cards, charts, maps, matrices, slicers, bookmarks, parameters, custom tooltips

---

## How to Run

1. Extract `data/AdventureWorks+Raw+Data.zip` for local source files.
2. Open `AdvWorks Final.pbix` in Power BI Desktop.
3. Configure data connections and refresh.
