| File | Type | Description |

| `HTML_CSS_for_Grafana_Dashboards.md` | Markdown | Quick reference |

---

## Why HTML/CSS for Grafana?

Grafana text panels support raw HTML — useful for:

- Custom KPI layouts and branded headers
- Styled tables beyond default panel options
- Conditional formatting with CSS classes
- Rich tooltips and annotation blocks

---

## Getting Started

1. Open `practice.html` in a browser to explore HTML/CSS fundamentals.
2. Copy patterns into Grafana **Text** panels (HTML mode).
3. Use the notebook for Grafana-specific examples.

```bash
git clone https://github.com/rupendra-bukke/html-css.git
cd html-css
# Open practice.html in your browser
```
