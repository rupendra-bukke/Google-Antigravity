## Overview

Hands-on study materials for data analysis fundamentals. Each topic is available as both a **Jupyter notebook** (interactive) and a **Markdown file** (quick reference).

| Guide | Notebook | Markdown | Topics |
|-------|----------|----------|--------|
| Python Complete | `Python_Complete_Learning_Guide.ipynb` | `.md` | Syntax, data structures, functions, OOP basics |
| NumPy | `NumPy_Numerical_Computing_Guide.ipynb` | `.md` | Arrays, vectorization, linear algebra |
| Pandas | `Pandas_Data_Analysis_Guide.ipynb` | `.md` | DataFrames, cleaning, aggregation, joins |
| Git Commands | `GIT_COMMANDS_GUIDE.ipynb` | `.md` | Version control for data projects |
| Practice | `python_learning1.ipynb` | `.md` | Short exercises |

## Getting Started

```bash
git clone https://github.com/rupendra-bukke/python-for-data-analysis.git
cd python-for-data-analysis
python -m venv .venv && source .venv/bin/activate
pip install jupyter pandas numpy
jupyter notebook
```

Open any `.ipynb` file and run cells top to bottom.
