## Overview

A step-by-step learning roadmap for Databricks — from workspace basics to advanced Spark SQL, Delta Lake, and production workflows.

| Resource | Format | Description |
|----------|--------|-------------|
| `Databricks_Learning_Roadmap.ipynb` | Jupyter | Interactive roadmap with exercises |
| `Databricks_Learning_Roadmap.md` | Markdown | Quick-reference version |

---

## Roadmap Topics

| Phase | Topics |
|-------|--------|
| **Foundations** | Workspace navigation, notebooks, clusters, DBFS |
| **Data Engineering** | Spark SQL, Delta Lake, ETL pipelines, Auto Loader |
| **Analytics** | SQL warehouses, dashboards, BI integration |
| **ML & Advanced** | MLflow, feature store, Unity Catalog, governance |

---

## Getting Started

```bash
git clone https://github.com/rupendra-bukke/databricks-learning.git
cd databricks-learning
jupyter notebook Databricks_Learning_Roadmap.ipynb
```

For hands-on practice, use a [Databricks free trial](https://www.databricks.com/try-databricks) or community edition.
